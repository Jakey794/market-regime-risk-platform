# Synthetic Demo Data

`synthetic_prices.parquet` is deterministic simulated adjusted-close data for
SPY, QQQ, XIU.TO, EFA, EEM, and XLK-like labels. It was generated with seed
`20260805` from a shared Gaussian component plus ticker-specific Gaussian noise.

It is not observed market data and must not be used for empirical investment
claims. Its only purpose is secret-free dashboard demonstration and testing.
